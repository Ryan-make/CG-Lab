# 粒子群算法可视化实验项目
## 项目简介
本项目基于 Python 实现标准粒子群优化算法（PSO），并完成可视化动态演示。程序通过模拟粒子群体在空间中更新速度与位置，依据个体最优、全局最优完成智能寻优，同时实时渲染粒子运动画面，实现可交互、可观测的粒子群动态效果，完整复现粒子群算法运行机制。

## 代码模块说明
1.  **`config.py` - 参数配置模块**
    统一管理所有实验参数，包括：
    - 粒子数量、迭代次数
    - 惯性权重、认知/社会学习因子
    - 搜索空间范围、初始速度限制
    - 可视化画布大小、帧率等

2.  **`physics.py` - 算法核心模块**
    实现粒子群算法的核心逻辑：
    - `Particle` 类：封装粒子的位置、速度、适应度、个体最优位置
    - `PSO` 类：实现粒子初始化、适应度计算、pbest/gbest 更新、速度/位置迭代公式
    - 边界处理逻辑，防止粒子超出搜索空间

3.  **`main.py` - 主程序与可视化模块**
    程序的入口与控制中心：
    - 读取 `config.py` 中的参数初始化粒子群
    - 调用 `physics.py` 中的 PSO 算法进行迭代
    - 使用可视化库（如 Matplotlib/Taichi）实时渲染粒子运动轨迹
    - 控制主循环，实现动画播放与结束条件判断

4.  **`test.py` - 测试与调试模块**
    用于：
    - 单独测试算法逻辑的正确性
    - 调试参数配置效果
    - 验证边界条件与特殊情况处理
