## 📖 实验目标
- 理解光线投射 (Ray Casting) 与光线追踪 (Ray Tracing) 的本质区别
- 掌握通过次级射线实现硬阴影与理想镜面反射的全局光照方法
- 学习将递归光线追踪改写为适合 GPU 并行计算的迭代模式

## 🧮 实验原理
采用 Whitted-Style 光线追踪模型。主光线击中表面后：
1. **阴影测试**：向光源发射阴影射线，若被遮挡则仅计算环境光。
2. **材质分支**：
   - 漫反射材质：按 Phong 模型计算颜色，终止传播。
   - 镜面材质：计算反射方向 $\mathbf{R} = \mathbf{I} - 2(\mathbf{I} \cdot \mathbf{N})\mathbf{N}$，生成反射射线继续传播，直到击中漫反射物体或达到最大弹射次数。

## ✨ 功能特性
- 隐式定义三维场景：棋盘格地面、红色漫反射球、银色镜面球
- 迭代式光线弹射（最大弹射次数可调）
- 硬阴影绘制，正确处理自相交偏移
- UI 实时调节光源位置与最大弹射次数
- 可选折射材质与抗锯齿（选做）

## 🔧 核心实现
- **场景与材质**：通过数学隐式函数定义平面、球体，使用材质 ID 区分漫反射与镜面。
- **迭代弹射**：每个像素循环最大弹射次数，用 `throughput` 追踪光线衰减，击中漫反射表面时叠加颜色并跳出循环。
- **阴影射线**：从交点向光源发射阴影射线，被遮挡则只保留环境光。
- **自相交预防**：所有次级射线起点沿法线方向偏移 `1e-4`，避免 Shadow Acne。
- **棋盘格纹理**：利用交点世界坐标的 `floor(x) + floor(z)` 奇偶性实现。

## 🎯 选做内容
### 1. 折射与玻璃材质
- 引入斯涅耳定律计算折射方向，将红色漫反射球改为玻璃球。
- 处理全反射临界角，内部反射射线继续传播。

### 2. 抗锯齿 (MSAA)
- 每个像素内随机采样多次，发射多条主射线，平均颜色以获得平滑边缘。
