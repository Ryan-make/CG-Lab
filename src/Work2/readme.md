# 贝塞尔曲线绘制实验

## 📖 实验目标
- 理解贝塞尔曲线 (Bézier Curve) 的几何意义
- 理解并实现 De Casteljau 算法
- 掌握光栅化基础：在像素缓冲区中直接操作和点亮像素
- 掌握 GUI 鼠标点击与交互事件处理

## 🧮 数学原理
贝塞尔曲线由一组控制点决定，参数 $t \in [0, 1]$ 从 0 连续变化到 1 时，所有采样点连成整条曲线。
De Casteljau 算法通过递归线性插值求解：
1. 对相邻控制点按比例 $t$ 插值，得到 $n-1$ 个新点：$P_i' = (1-t)P_i + t P_{i+1}$
2. 对新点集重复插值，直到只剩一个点，该点即为曲线在 $t$ 处的坐标。

## 🖥️ 光栅化实现
屏幕模拟为 800×800 的二维像素网格。通过将归一化浮点坐标（范围 [0,1]）映射到像素索引，直接修改对应像素的 RGB 值，实现“点亮像素”。

## ✨ 功能特性
- 鼠标左键添加控制点（最多 100 个）
- 实时绘制红色控制点、灰色控制多边形和绿色贝塞尔曲线
- 按键盘 `C` 键清空所有控制点
- 按键盘 `B` 键切换贝塞尔曲线 / B 样条曲线模式（选做）
- 支持反走样绘制，边缘更平滑（选做）

## ⚙️ 环境要求
- Python 3.8+
- Taichi ≥ 1.6.0
- NumPy

```bash
pip install taichi numpy
```


| 操作 | 功能 |
|------|------|
| 鼠标左键点击 | 在画布上添加控制点 |
| 键盘 `C` | 清空画布 |
| 键盘 `B` | 切换贝塞尔/B样条曲线模式 |

## 🔧 核心实现
- **CPU/GPU 分离**：在 CPU 端计算全部采样点，批量传入 GPU 并行绘制，避免逐点跨界通信
- **De Casteljau 算法**：纯 Python 递归线性插值
- **坐标映射**：`(x, y) = (int(px * 800), int(py * 800))`，内核中做边界检查
- **固定显存池**：控制点渲染使用定长 Taichi Field，未使用位置填屏幕外坐标

## 🎯 选做内容
### 1. 反走样
基于浮点坐标邻域（如 3×3）像素中心距离分配颜色权重，实现平滑抗锯齿效果。

### 2. B 样条曲线
- 采用均匀三次 B 样条，每 4 个控制点生成一段曲线
- 使用固定基矩阵分段计算，支持局部控制
- 按 `B` 键切换曲线类型，直观对比贝塞尔与 B 样条行为差异
